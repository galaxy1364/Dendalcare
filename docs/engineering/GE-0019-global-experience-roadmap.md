Clearly separate real device evidence from browser simulation; no unsupported native-platform claims.

## Design constitution
One coherent MinaDental identity, Persian RTL first, multilingual-ready; quiet surfaces, purposeful teal primary, semantic amber/red only for attention, clear light/dark contrast, no decorative competing elements. Use shared semantic tokens for spacing/type/radius/color, responsive content width, platform insets, keyboard and screen-reader semantics, purposeful haptics, reduced motion. Target WCAG 2.2 AA, not a certification; 4.5:1 normal text/3:1 large text, 3:1 meaningful non-text boundaries, reflow at 320 CSS px, 200% text resize, no obscured focus, keyboard alternative to drag. Project touch target goal 48 CSS px / Android 48dp / Apple 44pt where practical, not conflating these with WCAG minimum 24 CSS px. Never hide or compress safety-critical clinical action to achieve a no-scroll aesthetic.

3. **Living tooth** — prior rig independently animates eyes, brows, mouth, arms and tear/sweat; currently not visual/device verified. Calm neutral when read model unknown, orange for verified pending, red for verified critical/overdue; happy only on verified complete read model, celebration only explicit confirmed completion; no patient identifiers, no guilt or invented completion. 4. **Clinical modules** — patients: responsive list/detail, search, identity matching, permission-safe data, verified create/edit, audit and no duplicate/incorrect patient. For each route: loading/empty/error/partial/offline/unauthorized/ready, safe save/retry, responsive list-detail, keyboard, screen-reader, test synthetic fixtures and negative RLS cases. Baseline INP/LCP/CLS and device frame pacing; target good Core Web Vitals where measurable, not unsupported speed claims. Test slow network, offline queue, stale data, update during clinical draft, multi-tab and scope changes. Real device sign-off separately; use synthetic data only. Security review backups, cleartext policy, WebView bridge and notification scope/retention. No destructive storage actions.
